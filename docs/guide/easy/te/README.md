# మృదంగ సేవ యాప్ — సులభ మార్గదర్శి

హరే కృష్ణ. 🙏

చదవండి: [English](../README.md) · **తెలుగు** · [हिन्दी](../hi/README.md)

ఇది **సులభ మార్గదర్శి**. కంప్యూటర్లు, యాప్‌ల గురించి తెలియని అందరి కోసం:

- మృదంగం నేర్చుకోవడానికి వచ్చే **పాఠశాల పిల్లలు**, వారి తల్లిదండ్రులు,
- **కళాశాల విద్యార్థులు**,
- తల్లిదండ్రులుగా, కోఆర్డినేటర్లుగా లేదా సేవకులుగా తరగతికి సేవ చేసే **డాక్టర్లు, నర్సులు,
  వైద్య రంగంలోని ఇతరులు**.

యాప్‌లో బటన్ పేర్లు **బోల్డ్ అక్షరాలలో** ఉన్నాయి, బ్రాకెట్‌లో ఇంగ్లీష్ పేరు కూడా ఉంది (యాప్ ఇంగ్లీష్‌లో
ఉంటే అలా కనిపిస్తుంది).

> ఇది అనువాద ముసాయిదా. ఏదైనా పదం సరిగా లేకపోతే కోఆర్డినేటర్‌కు చెప్పండి.

## యాప్ మూడు మాటల్లో

1. **ఇది ఫోన్‌లో మన తరగతి రిజిస్టర్.** ఎవరు వచ్చారు, ఎప్పుడు, ఏమి నేర్చుకున్నారు.
2. **ఇది మన చాలా వాట్సాప్ గ్రూపుల స్థానంలో వస్తుంది.** తరగతి వార్తలు, పాఠాలు, కార్యక్రమాలు అన్నీ ఒకే చోట.
3. **ఇది సేవగా చేయబడింది** (శ్రీకృష్ణుడికి సేవ). ఇది ఉచితం, అందరి వివరాలను సురక్షితంగా ఉంచుతుంది.

## మీరు చూసే పదాలు

| పదం | సులభ అర్థం |
|---|---|
| **మృదంగం** (**ఖోల్** అని కూడా) | కీర్తనలో మనం వాయించే మట్టి లేదా ఫైబర్‌గ్లాస్ డోలు |
| **కీర్తన** | భగవన్నామాలను అందరం కలిసి పాడటం |
| **సేవ** | డబ్బు ఆశించకుండా ప్రేమతో చేసే పని |
| **గురువు** | తరగతిని నడిపించే గురువుగారు (ఇంగ్లీష్ యాప్‌లో "Facilitator" అని ఉంటుంది) |
| **కోఆర్డినేటర్** | ప్రతి రోజు తరగతిని నడిపి, నేర్పించే సీనియర్ భక్తులు |
| **రోల్ నంబర్** | మీ తరగతి గుర్తింపు సంఖ్య, `MS-2026-0001` లాగా. ఇది జీవితాంతం మీదే |
| **QR కోడ్** | మీ ఫోన్‌లోని నలుపు-తెలుపు చతురస్ర బొమ్మ; మీరు రాగానే కోఆర్డినేటర్ దాన్ని స్కాన్ చేస్తారు |
| **స్థాయి** | ప్రారంభ స్థాయి, మధ్యమ స్థాయి, ఉన్నత స్థాయి |
| **బోల్** | ఒక దెబ్బ పేరు, *తా* లేదా *ధిన్* లాగా |
| **తాళం** | ఒక లయ చక్రం, 8 మాత్రల కహర్వా లాగా |

## ఏదైనా సమస్య వస్తే

- తరగతిలో ఏ **కోఆర్డినేటర్‌నైనా** అడగండి. వారు సంతోషంగా సహాయం చేస్తారు.
- మీ హోమ్ స్క్రీన్ చివరన ఉన్న చిన్న లైన్ (*Version* తో మొదలయ్యేది) వారికి చూపించండి. మీ దగ్గర యాప్ ఏ
  వెర్షన్ ఉందో అది చెబుతుంది.
- అటూ ఇటూ నొక్కడం వల్ల యాప్ పాడవదు. ఏదైనా ముఖ్యమైనది తొలగించే లేదా మార్చే ముందు యాప్ "నిజంగానా?" అని
  అడుగుతుంది. ప్రయత్నించండి, అనుమానం ఉంటే అడగండి.

ప్రతి స్క్రీన్, ప్రతి బటన్ ఉన్న పూర్తి మార్గదర్శి (ఇంగ్లీష్‌లో): [పూర్తి మార్గదర్శి](../../README.md).
